# 类和实例

## 📚 概述

类是面向对象编程的基础，它定义了对象的属性和方法。实例是根据类创建的具体对象。

## 🎯 核心概念

### 1. 定义类

使用 `class` 关键字定义类：

```python
class Student:
    """学生类"""

    def __init__(self, name, age):
        """构造函数，初始化实例属性"""
        self.name = name
        self.age = age
```

**要点**：

- `__init__` 是构造函数，在创建实例时自动调用
- `self` 代表实例本身，必须作为第一个参数
- 通过 `self.属性名` 定义实例属性

### 2. 创建实例

```python
student1 = Student("张三", 20)
student2 = Student("李四", 22)
```

### 3. 访问属性和方法

```python
# 访问属性
print(student1.name)  # 张三
print(student1.age)   # 20

# 调用方法
print(student1.introduce())  # 我是张三，今年20岁
```

### 4. 类属性 vs 实例属性

| 类型         | 定义位置                   | 访问方式                   | 特点         |
| ------------ | -------------------------- | -------------------------- | ------------ |
| **类属性**   | 类定义中，方法外           | `类名.属性` 或 `实例.属性` | 所有实例共享 |
| **实例属性** | `__init__` 中，通过 `self` | `实例.属性`                | 每个实例独有 |

**示例**：

```python
class Dog:
    species = "犬科"  # 类属性

    def __init__(self, name):
        self.name = name  # 实例属性
```

## 💡 实际应用

### 银行账户示例

```python
class BankAccount:
    bank_name = "Python银行"  # 类属性

    def __init__(self, account_number, owner, balance=0):
        self.account_number = account_number
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        """存款"""
        if amount > 0:
            self.balance += amount
            return f"存款成功，当前余额: {self.balance}"
        return "存款金额必须大于0"
```

## 🔑 关键点

1. **`self` 的作用**：指向当前实例，必须作为方法的第一个参数
2. **`__init__` 方法**：构造函数，用于初始化实例属性
3. **动态添加属性**：Python 允许在运行时添加属性（不推荐）
4. **类属性共享**：所有实例共享类属性，修改会影响所有实例

## 📝 最佳实践

1. **命名规范**：类名使用大驼峰（PascalCase），如 `Student`
2. **文档字符串**：为类和方法添加文档字符串
3. **属性初始化**：在 `__init__` 中初始化所有必要的属性
4. **方法设计**：方法应该专注于单一职责
