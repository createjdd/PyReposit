## 📖 核心概念

### 类和对象
- **类（Class）**：定义对象的模板
- **实例（Instance）**：根据类创建的具体对象
- **属性（Attribute）**：对象的数据
- **方法（Method）**：对象的行为

### 面向对象三大特性
1. **封装**：将数据和方法封装在类中
2. **继承**：子类继承父类的属性和方法
3. **多态**：不同类对同一方法有不同的实现

### 访问控制
- **公开（Public）**：无下划线，可以从外部访问
- **受保护（Protected）**：单下划线 `_`，约定不推荐外部访问
- **私有（Private）**：双下划线 `__`，通过名称改写实现
