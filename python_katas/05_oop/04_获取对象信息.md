# 获取对象信息

## 📚 概述

在 Python 中，有多种方式可以获取对象的类型、属性、方法等信息，这对于调试、反射和动态编程非常有用。

## 🎯 常用方法

### 1. type() - 获取对象类型

```python
num = 123
text = "hello"
lst = [1, 2, 3]

print(type(num))   # <class 'int'>
print(type(text))  # <class 'str'>
print(type(lst))   # <class 'list'>

# 比较类型
print(type(num) == int)  # True
```

**用途**：检查对象的确切类型

### 2. isinstance() - 类型检查（推荐）

```python
class Animal:
    pass

class Dog(Animal):
    pass

dog = Dog()
print(isinstance(dog, Dog))      # True
print(isinstance(dog, Animal))   # True
print(isinstance(dog, object))   # True

# 检查多个类型
print(isinstance(dog, (Dog, Animal)))  # True
```

**优势**：
- ✅ 支持继承关系检查
- ✅ 可以检查多个类型
- ✅ 比 `type()` 更灵活

### 3. dir() - 获取所有属性和方法

```python
class Person:
    def __init__(self, name):
        self.name = name
    
    def introduce(self):
        return f"我是{self.name}"

person = Person("张三")
print(dir(person))  # 返回所有属性和方法的列表
```

**输出示例**：
```python
['__class__', '__dict__', '__doc__', '__init__', 
 'introduce', 'name', ...]
```

### 4. hasattr() - 检查是否有属性

```python
person = Person("张三")
print(hasattr(person, 'name'))        # True
print(hasattr(person, 'introduce'))   # True
print(hasattr(person, 'age'))         # False
```

**用途**：在访问属性前检查是否存在，避免 AttributeError

### 5. getattr() - 获取属性值

```python
# 获取属性
name = getattr(person, 'name')
print(name)  # 张三

# 如果属性不存在，可以设置默认值
age = getattr(person, 'age', 0)  # 默认值为 0
print(age)   # 0

# 获取方法并调用
introduce_method = getattr(person, 'introduce')
print(introduce_method())  # 我是张三
```

**用途**：动态获取属性，支持默认值

### 6. setattr() - 设置属性

```python
setattr(person, 'age', 25)
setattr(person, 'city', '北京')
print(person.age)   # 25
print(person.city)  # 北京
```

**用途**：动态设置属性

### 7. __dict__ - 获取属性字典

```python
person = Person("张三")
person.age = 25
print(person.__dict__)
# 输出：{'name': '张三', 'age': 25}
```

**用途**：查看对象的所有实例属性

### 8. __class__ - 获取对象的类

```python
person = Person("张三")
print(person.__class__)           # <class '__main__.Person'>
print(person.__class__.__name__)  # Person
```

### 9. __module__ - 获取模块名

```python
print(Person.__module__)  # __main__ 或模块名
```

### 10. __doc__ - 获取文档字符串

```python
class Person:
    """人类"""
    pass

print(Person.__doc__)  # 人类
```

## 🔧 inspect 模块

`inspect` 模块提供更强大的检查功能：

```python
import inspect

# 获取类的所有方法
methods = inspect.getmembers(Person, predicate=inspect.ismethod)

# 获取函数的参数信息
sig = inspect.signature(Person.__init__)
print(sig)  # (name)

# 获取源代码
print(inspect.getsource(Person))
```

## 💡 实际应用

### 对象信息查看器

```python
def object_info(obj):
    """获取对象的详细信息"""
    info = {
        'type': type(obj).__name__,
        'class': obj.__class__.__name__,
        'module': obj.__class__.__module__,
        'attributes': {},
        'methods': []
    }
    
    # 获取实例属性
    if hasattr(obj, '__dict__'):
        info['attributes'] = obj.__dict__
    
    # 获取方法
    for name in dir(obj):
        if not name.startswith('__'):
            attr = getattr(obj, name)
            if callable(attr):
                info['methods'].append(name)
    
    return info
```

## 📊 方法对比

| 方法 | 用途 | 返回值 | 是否支持继承 |
|------|------|--------|-------------|
| `type()` | 获取类型 | 类型对象 | ❌ |
| `isinstance()` | 类型检查 | bool | ✅ |
| `dir()` | 列出所有属性 | list | ✅ |
| `hasattr()` | 检查属性存在 | bool | ✅ |
| `getattr()` | 获取属性值 | 属性值 | ✅ |
| `setattr()` | 设置属性 | None | ✅ |

## 🎯 使用场景

1. **调试**：查看对象的属性和方法
2. **反射**：动态调用方法和访问属性
3. **序列化**：获取对象的所有属性
4. **验证**：检查对象是否符合要求
5. **文档生成**：自动生成 API 文档

## ⚠️ 注意事项

1. **性能考虑**：`dir()` 和 `inspect` 可能较慢，避免在循环中使用
2. **私有属性**：双下划线属性会被名称改写，注意检查方式
3. **特殊方法**：`__dict__` 等特殊属性可能不存在于某些对象
