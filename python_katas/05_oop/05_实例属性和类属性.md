# 实例属性和类属性

## 📚 概述

Python 中有两种类型的属性：**实例属性**和**类属性**。理解它们的区别对于正确使用面向对象编程非常重要。

## 🎯 核心区别

### 实例属性

- **定义位置**：在 `__init__` 方法中，通过 `self` 定义
- **访问方式**：通过实例访问 `实例.属性`
- **特点**：每个实例都有自己独立的属性值

```python
class Student:
    def __init__(self, name):
        self.name = name  # 实例属性

student1 = Student("张三")
student2 = Student("李四")
print(student1.name)  # 张三
print(student2.name)  # 李四
```

### 类属性

- **定义位置**：在类定义中，方法外
- **访问方式**：通过类或实例访问 `类名.属性` 或 `实例.属性`
- **特点**：所有实例共享同一个属性值

```python
class Student:
    school = "Python大学"  # 类属性
    
    def __init__(self, name):
        self.name = name  # 实例属性

student1 = Student("张三")
student2 = Student("李四")
print(student1.school)  # Python大学
print(student2.school)   # Python大学
print(Student.school)    # Python大学
```

## 🔄 属性查找顺序

当通过实例访问属性时，Python 按以下顺序查找：

1. **实例属性**（优先）
2. **类属性**（如果实例属性不存在）
3. **父类属性**（如果类属性不存在）

```python
class Example:
    class_attr = "类属性"
    
    def __init__(self):
        self.instance_attr = "实例属性"
        self.class_attr = "实例属性（覆盖类属性）"

obj = Example()
print(obj.class_attr)  # 实例属性（覆盖类属性）- 优先使用实例属性
print(Example.class_attr)  # 类属性 - 类属性仍然存在

# 删除实例属性后，会使用类属性
del obj.class_attr
print(obj.class_attr)  # 类属性
```

## 📊 修改类属性

### 通过类修改（影响所有实例）

```python
class Student:
    school = "Python大学"

student1 = Student("张三")
student2 = Student("李四")

# 通过类修改
Student.school = "新Python大学"
print(student1.school)  # 新Python大学
print(student2.school)   # 新Python大学
```

### 通过实例修改（只影响该实例）

```python
# 通过实例修改（实际上是创建了实例属性）
student1.school = "个人学校"
print(student1.school)  # 个人学校（实例属性）
print(student2.school)   # 新Python大学（类属性）
print(Student.school)    # 新Python大学（类属性）
```

## 💡 类属性的常见用途

### 1. 存储配置信息

```python
class Database:
    host = "localhost"
    port = 5432
    database = "mydb"
    
    @classmethod
    def configure(cls, host, port, database):
        """类方法：配置数据库连接"""
        cls.host = host
        cls.port = port
        cls.database = database
```

### 2. 统计实例数量

```python
class Counter:
    count = 0  # 类属性：统计实例数量
    
    def __init__(self, name):
        self.name = name
        Counter.count += 1  # 每次创建实例时增加计数
        self.id = Counter.count
```

### 3. 存储常量

```python
class MathUtils:
    pi = 3.14159  # 类属性：常量
    e = 2.71828
```

## 🎨 类方法和静态方法

### 类方法（@classmethod）

类方法可以访问类属性，但不能访问实例属性：

```python
class MathUtils:
    pi = 3.14159
    
    @classmethod
    def get_pi(cls):
        """类方法：获取圆周率"""
        return cls.pi
    
    @classmethod
    def from_string(cls, value_str):
        """类方法：从字符串创建实例"""
        return cls(float(value_str))
```

**特点**：
- 第一个参数是 `cls`（类本身）
- 可以访问类属性
- 可以通过类或实例调用

### 静态方法（@staticmethod）

静态方法不需要访问类或实例：

```python
class MathUtils:
    @staticmethod
    def add(a, b):
        """静态方法：不需要访问类或实例"""
        return a + b
```

**特点**：
- 不需要 `self` 或 `cls` 参数
- 不能访问类或实例属性
- 可以通过类或实例调用

## 📊 对比表

| 特性 | 实例属性 | 类属性 | 类方法 | 静态方法 |
|------|---------|--------|--------|---------|
| **定义位置** | `__init__` 中 | 类定义中 | 类定义中 | 类定义中 |
| **访问实例属性** | ✅ | ❌ | ❌ | ❌ |
| **访问类属性** | ✅ | ✅ | ✅ | ❌ |
| **第一个参数** | `self` | - | `cls` | - |
| **调用方式** | `实例.方法()` | `类.属性` | `类.方法()` | `类.方法()` |
| **用途** | 实例特有数据 | 共享数据 | 操作类属性 | 工具函数 |

## 💡 最佳实践

1. **使用类属性存储共享数据**：如配置、常量、统计信息
2. **使用实例属性存储实例特有数据**：如姓名、年龄等
3. **使用类方法操作类属性**：如配置、工厂方法
4. **使用静态方法提供工具函数**：不依赖类或实例

## ⚠️ 常见错误

### 错误 1：在类方法中访问实例属性

```python
class Example:
    @classmethod
    def method(cls):
        print(self.name)  # ❌ 错误：类方法没有 self
```

### 错误 2：误用类属性

```python
class Example:
    items = []  # ❌ 危险：所有实例共享同一个列表
    
    def add_item(self, item):
        self.items.append(item)  # 会影响所有实例
```

**正确做法**：
```python
class Example:
    def __init__(self):
        self.items = []  # ✅ 每个实例有自己的列表
    
    def add_item(self, item):
        self.items.append(item)
```
