# 继承和多态

## 📚 概述

继承允许一个类（子类）继承另一个类（父类）的属性和方法。多态允许不同的类对同一方法有不同的实现。

## 🎯 基本继承

### 1. 定义继承关系

```python
class Animal:
    """动物基类"""
    def __init__(self, name):
        self.name = name
    
    def speak(self):
        return f"{self.name} 发出了声音"


class Dog(Animal):
    """狗类 - 继承自 Animal"""
    def speak(self):
        """重写父类方法"""
        return f"{self.name} 汪汪叫"
```

**语法**：`class 子类(父类):`

### 2. 方法重写（Override）

子类可以重写父类的方法：

```python
class Cat(Animal):
    def speak(self):
        return f"{self.name} 喵喵叫"
```

### 3. 调用父类方法

使用 `super()` 调用父类方法：

```python
class Bird(Animal):
    def __init__(self, name, can_fly=True):
        super().__init__(name)  # 调用父类的 __init__
        self.can_fly = can_fly
    
    def speak(self):
        base_sound = super().speak()  # 调用父类方法
        return f"{base_sound}，{self.name} 啾啾叫"
```

## 🔄 多态性

多态允许不同的类对同一方法有不同的实现：

```python
def animal_speak(animal):
    """多态函数 - 可以接受任何 Animal 子类"""
    return animal.speak()

# 使用
animals = [Dog("旺财"), Cat("小花"), Bird("鹦鹉")]
for animal in animals:
    print(animal_speak(animal))  # 同一个函数，不同的行为
```

**多态的好处**：
- 代码更灵活
- 易于扩展
- 符合开闭原则（对扩展开放，对修改关闭）

## 🔗 多重继承

Python 支持多重继承：

```python
class Flyable:
    def fly(self):
        return "正在飞行"

class Swimmable:
    def swim(self):
        return "正在游泳"

class Duck(Animal, Flyable, Swimmable):
    """鸭子类 - 多重继承"""
    def speak(self):
        return f"{self.name} 嘎嘎叫"
```

### 方法解析顺序（MRO）

Python 使用 C3 算法确定方法解析顺序：

```python
print(Duck.__mro__)
# 输出：(<class '__main__.Duck'>, <class '__main__.Animal'>, 
#        <class '__main__.Flyable'>, <class '__main__.Swimmable'>, 
#        <class 'object'>)
```

## 📐 完整示例：图形类

```python
class Shape:
    """图形基类"""
    def __init__(self, name):
        self.name = name
    
    def area(self):
        raise NotImplementedError("子类必须实现 area 方法")
    
    def perimeter(self):
        raise NotImplementedError("子类必须实现 perimeter 方法")


class Rectangle(Shape):
    """矩形类"""
    def __init__(self, width, height):
        super().__init__("矩形")
        self.width = width
        self.height = height
    
    def area(self):
        return self.width * self.height
    
    def perimeter(self):
        return 2 * (self.width + self.height)


class Circle(Shape):
    """圆形类"""
    def __init__(self, radius):
        super().__init__("圆形")
        self.radius = radius
    
    def area(self):
        return 3.14159 * self.radius ** 2
    
    def perimeter(self):
        return 2 * 3.14159 * self.radius
```

## 🔍 类型检查

### isinstance() - 检查实例类型

```python
rect = Rectangle(5, 3)
print(isinstance(rect, Rectangle))  # True
print(isinstance(rect, Shape))      # True
print(isinstance(rect, Circle))     # False
```

### issubclass() - 检查继承关系

```python
print(issubclass(Rectangle, Shape))  # True
print(issubclass(Square, Rectangle))  # True
```

## 💡 设计原则

### 1. 里氏替换原则（LSP）

子类对象应该能够替换父类对象，而不影响程序的正确性。

### 2. 开闭原则（OCP）

对扩展开放，对修改关闭。通过继承扩展功能，而不是修改现有代码。

### 3. 单一职责原则（SRP）

每个类应该只有一个职责。

## ⚠️ 注意事项

1. **避免过度继承**：继承层次不要太深（建议不超过 3-4 层）
2. **优先使用组合**：如果关系不是"是一个"，考虑使用组合而不是继承
3. **多重继承要谨慎**：容易导致代码复杂，优先使用组合或接口
