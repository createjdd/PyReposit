# 访问限制

## 📚 概述

Python 通过命名约定来实现访问控制，虽然没有严格的私有/公有机制，但通过下划线约定来区分属性的可见性。

## 🎯 三种访问级别

### 1. 公开属性（无下划线）

```python
class PublicClass:
    def __init__(self):
        self.public_attr = "这是公开属性"  # 可以从外部访问
```

**特点**：

- ✅ 可以从外部直接访问
- ✅ 可以从外部直接修改
- 适用于：需要外部访问的属性

### 2. 受保护属性（单下划线 `_`）

```python
class ProtectedClass:
    def __init__(self):
        self._protected_attr = "这是受保护属性"  # 约定：不应该从外部访问
```

**特点**：

- ⚠️ 技术上可以访问，但不推荐
- ⚠️ 这是**约定**，不是强制限制
- 适用于：子类可以访问，但外部不应该直接访问

**约定**：

- 单下划线表示"受保护"，建议不要从外部访问
- 子类可以访问和使用

### 3. 私有属性（双下划线 `__`）

```python
class PrivateClass:
    def __init__(self):
        self.__private_attr = "私有属性"  # 会被改写为 _PrivateClass__private_attr
```

**特点**：

- ❌ 不能直接通过 `obj.__private_attr` 访问
- ✅ 通过名称改写（Name Mangling）实现
- ✅ 可以通过 `obj._PrivateClass__private_attr` 访问（但不推荐）

**名称改写机制**：

```python
# 定义
self.__private_attr = "私有"

# 实际存储为
self._PrivateClass__private_attr = "私有"
```

## 🔒 实际应用

### 银行账户示例

```python
class BankAccount:
    def __init__(self, account_number, owner, initial_balance=0):
        self.account_number = account_number  # 公开
        self.owner = owner                    # 公开
        self.__balance = initial_balance      # 私有：不能直接修改
        self.__transaction_history = []       # 私有：交易历史

    def deposit(self, amount):
        """存款 - 通过方法修改余额"""
        if amount > 0:
            self.__balance += amount
            return f"存款成功，当前余额: {self.__balance}"
        return "存款金额必须大于0"

    def get_balance(self):
        """查询余额 - 只读访问"""
        return self.__balance
```

**为什么使用私有属性**：

- 保护数据不被意外修改
- 可以添加验证逻辑
- 控制数据的访问方式

## 🎨 @property 装饰器

使用 `@property` 使方法可以像属性一样访问：

```python
class Temperature:
    def __init__(self, celsius=0):
        self.__celsius = celsius

    @property
    def celsius(self):
        """获取摄氏温度"""
        return self.__celsius

    @celsius.setter
    def celsius(self, value):
        """设置摄氏温度（带验证）"""
        if value < -273.15:
            raise ValueError("温度不能低于绝对零度")
        self.__celsius = value
```

**使用**：

```python
temp = Temperature(25)
print(temp.celsius)      # 像属性一样访问
temp.celsius = 30         # 像属性一样设置（会调用 setter）
```

## 📊 访问级别对比

| 访问级别   | 命名         | 外部访问  | 子类访问 | 用途     |
| ---------- | ------------ | --------- | -------- | -------- |
| **公开**   | 无下划线     | ✅ 可以   | ✅ 可以  | 公共接口 |
| **受保护** | `_单下划线`  | ⚠️ 不推荐 | ✅ 可以  | 子类接口 |
| **私有**   | `__双下划线` | ❌ 不能   | ❌ 不能  | 内部实现 |

## 💡 最佳实践

1. **默认使用公开属性**：除非有特殊需求
2. **需要保护时使用私有属性**：如账户余额、敏感数据
3. **使用 @property**：提供更优雅的属性访问方式
4. **通过方法修改私有属性**：添加验证和逻辑

## ⚠️ 注意事项

1. **Python 的"私有"是约定**：不是真正的私有，可以通过名称改写访问
2. **不要过度使用私有属性**：Python 哲学是"我们都是成年人"
3. **受保护属性是约定**：单下划线只是约定，不是强制限制
